# Mindset Academics 🎓
 
> An online tutoring platform built to showcase our skills and tutoring services to help students unlock their potential through personalised sessions.
 
---
 
## 🚧 Status
 
This project is in the **website development** phase. We're currently building the website, as shown in this repo.
 
---
 
## 💡 About
 
Mindset Academics is an online tutoring platform connecting parents & students with tutors who emphasise not just academic knowledge but the growth-mindset skills needed to thrive, including confidence, resilience, and independent thinking.

## Next.js info

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Modify `app/page.tsx` to start editing the page. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
